3. AUTHENTICATION SYSTEM

Replace all fake/mock auth systems.

Build real:

A. REGISTER API
POST /api/auth/register

Features:

* email validation
* password hashing
* duplicate email prevention
* username uniqueness
* JWT generation

B. LOGIN API
POST /api/auth/login

Features:

* secure password verification
* JWT access token
* refresh token structure
* secure cookie support

C. CURRENT USER API
GET /api/auth/me

D. LOGOUT API
POST /api/auth/logout
